## A. Raster Leaflet logistics map

Input: [raster-leaflet.js](../fixtures/raster-leaflet.js).

Task: make roads and labels quieter and business sites clearer, preserving the
provider and state-color meaning; deliver an implementable proposal first.

Observed output:

- Identified the existing PNG tile layer as baked raster content and separated
  it from CircleMarker and DOM styling.
- Stated that selective road/label restyling was unavailable with that source.
- Proposed optional tile-layer opacity as an explicitly whole-raster approximation,
  preserving business overlays and attribution outside the fade.
- Retained normal/alert color associations, source coordinates, provider, and
  feature identity. Proposed a white outline and modest size change for sites.
- Distinguished static observations from missing screenshots and runtime evidence.
- Supplied a verification and restoration plan without claiming either had run.

Assessment: **passed for the requested source-based proposal**. This does not
establish visual quality of the proposed opacity or actual page behavior.

## B. Mapbox day/night route persistence

Input: [style-switch-mapbox.js](../fixtures/style-switch-mapbox.js).

Task: review whether the route can remain stable through day/night switching;
give the necessary modification example and verification method.

Observed output:

- Located route creation under initial `load` and the later `setStyle` call.
- Proposed one `style.load` restoration path, adding the owned source before
  its layer and checking for existing IDs to avoid duplicates.
- Kept route data, coordinates, color, and width unchanged; distinguished
  GeoJSON `properties.id` from a feature-state feature ID.
- Used the fixture's classic-style path rather than assuming Standard config/slots.
- Included teardown and repeated/rapid switch checks. Identified error/readiness
  UI as remaining integration work and did not guarantee zero transition flicker.
- Labeled example code and checks as unexecuted; did not invent credentials.

Assessment: **passed for the requested static review and modification example**.
The example was not integrated, built, or exercised with a Mapbox token.
