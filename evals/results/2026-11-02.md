# v0.2 evaluation evidence — reviewed 2026-11-02

This record replaces unsupported claims in the earlier local v0.2 report. The
original inputs were backed up before review. Fixture regression, agent behavior
evaluation, and A/B experiments are different forms of evidence.

## Executable fixture regression

The [case verifier](../../scripts/verify_cases.mjs) runs hand-authored Leaflet
raster and **MapLibre GL JS 6.16.0** local GeoJSON cases in Chromium. It starts its
own temporary loopback server and closes it afterward. Mapbox GL JS is not run.

Results: [verification-report.json](../../cases/evidence/verification-report.json).
Assertions and observations are counted separately. Expected baseline defects
are observations, not passing assertions. Checks cover loaded input bytes,
rendered geometry/properties, retained attribution, actual map clicks, popup and
feature state, eight serial style replacements, resource counts, relative layer
ordering, real legend colors, five diverging classes, SVG missing-value hatch,
camera/container agreement, label overlap, and mobile sheet occlusion.

Pixel results: [pixel-measurements.json](../../cases/evidence/pixel-measurements.json).
Thresholds are fixture heuristics, not WCAG contrast or a beauty score. Missing
images, mismatched dimensions, or a mismatched screenshot hash fail measurement.

## Agent evaluations

The original v0.1 history records two source-based proposal evaluations. Those
are not executions of the new runnable fixture tasks. This review did not run
new agent contexts or measure model effectiveness. Existing outputs were later
replayed post hoc; that is not a new independent execution. Remaining
[behavioral cases](../cases.md) are specifications without execution evidence.

## Direct-versus-skill A/B: supplied attempt executed, comparison invalid

[The subsequent A/B audit](../ab-reviews/2026-11-02/README.md) inspected actual
transcripts and tool receipts supplied after the earlier review. They confirm
two executions, but A read B's skill and both arms read/copied reference answers.
This supersedes the earlier "not executed" status with **executed but invalid**.

[make_ab_copies.py](../../scripts/make_ab_copies.py) still prepares inputs only.
It cannot enforce filesystem isolation. The old causal conclusions and the
later claim that only B achieved acceptable architecture are not retained.
An aligned replay found identical improved desktop/mobile PNGs for these
contaminated outputs; that does not establish either a skill benefit or no benefit.

A future comparison needs separately retained executor inputs, permitted
workspaces, commands, outputs, and the same scoring rubric. Separate directories
do not themselves enforce filesystem isolation. The preparation tool preserves
existing experiments and creates a new directory instead of deleting prior runs.

## Unverified integrations

Mapbox GL JS, Standard, ArcGIS, AMap, and Baidu have not been exercised with their
actual services. The Mapbox example has limited Node API-contract-double tests,
not a Mapbox renderer test. This review does not infer payment, enterprise
identity, or license requirements for every user scenario.

The eight-switch test is serial and checks selected state and owned resources.
It does not measure heap memory, all listeners, every race, or zero flicker.
No physical touch-device, production-performance, or user-perception study ran.
See [verification](../../docs/verification.md) for commands and limits.
