# 场景决策指南：点位密集 (Dense Points)

点要素在多尺度下互相叠压、符号边界重合、掩盖地理底图与道路背景，导致无法辨识独立点位及其业务属性。

## 1. 观察依据 (Observational Basis)

- **符号叠压率高**：在当前工作尺度或全景尺度下，多个点标记（Marker / Circle）的几何外接矩形或碰撞包围盒大面积重叠。
- **信息遮盖**：密集点群形成大片无法辨识的“色块”，遮盖了底图主要交通干道、水体及行政区划骨架。
- **状态失真**：当状态为“异常”的点与“正常”的点堆叠在一起时，上层符号覆盖下层符号，导致严重告警被遮蔽或产生虚假的聚集假象。

## 2. 可能原因 (Probable Causes)

- 点要素符号尺寸（`radiusPx`）固定，未随地面分辨率（Meters Per Pixel, MPP）进行自适应缩放。
- 在全景与中间尺度未配置分级展示规则或聚合（Clustering）机制，无差别加载全部明细点。
- 点符号描边过宽或颜色与填充色缺乏区隔，加剧了密集区域的视觉噪点。

## 3. 编辑表面 (Editable Surfaces)

- **业务矢量图层**：点要素图层的 `radius`（半径）、`stroke`（外描边）、`opacity`（透明度）。
- **空间聚合/过滤逻辑**：数据源聚合（Supercluster / Leaflet.markercluster / SDK 原生 Cluster）或按视域分级筛选。
- **DOM 覆盖物**：针对 HTML 标记的尺寸自适应或碰撞隐藏机制。

## 4. 优先调整顺序 (Priority Adjustment Order)

1. **依尺度阶梯化符号尺寸**：远景缩小半径（3–5px），近景放大至工作尺寸（6–9px），减少重叠面积。
2. **强化符号外描边（Knockout Stroke）**：为点符号增加与背景或底图一致的高对比度外描边（1–2px），使重叠的相邻圆点依然能分辨各自轮廓。
3. **基于业务指标的分级显隐（Tiering）**：优先展示核心枢纽、高吞吐站点或告警异常站点，次级站点退居更近尺度。
4. **引入空间聚类（Clustering）**：在远景将稠密点群聚合为带数量指示的簇标记，点击展开或缩放展开。

## 5. 建议参数范围及适用条件 (Recommended Parameters)

- **点半径 (`radiusPx`)**：
  - 全景概览（MPP > 8）：`3px – 5px`
  - 工作视图（3 < MPP ≤ 8）：`5px – 7px`
  - 局部近景（MPP ≤ 3）：`7px – 10px`
- **描边宽度 (`strokeWidthPx`)**：`1px – 2px`，描边颜色通常建议使用纯白 `#FFFFFF`（浅色主题）或暗底 `#1B242A`（深色主题），或使用半透明环。
- **透明度 (`fillOpacity`)**：在大量重叠且无聚合时，可将填充透明度降至 `0.7 – 0.85`，利用色彩叠加感知密度；在需要精确读出离散分类时应保持 `1.0`。

## 6. 不可破坏的数据语义 (Preserved Data Semantics)

- **不得随意平移真实坐标**：严禁为了排版“美观”而偏离要素的真实经纬度坐标。
- **不得吞没告警状态**：若存在包含异常/告警站点的稠密簇，聚合标记或最高层级渲染必须明确传递“包含告警”的语义。
- **分类标识必须可读**：即使缩小半径，关键类别属性（如枢纽仓 vs 自提点）的色调与符号形状仍须保持可区分性。

## 7. 能力不足时的替代方案 (Fallbacks When Capability Is Lacking)

- **无原生聚合引擎（如轻量 Leaflet 环境）**：
  - 替代方案：基于数据属性划分 Tier（如 `throughput >= 1200` 为核心级），在不同 zoom 下由前端过滤函数决定渲染子集。
  - 避免方案：不要强行引入笨重且修改 DOM 结构的第三方未经测试插件，优先采用静态阶梯过滤。

## 8. 验收方法 (Acceptance Methods)

- **功能正确性**：缩放至细节尺度时，所有离散站点数量与源数据一一对应；点击任一可见点均能准确打开对应站点弹窗。
- **审美效果评估**：在全景下，重叠边界具有清晰的外描边区隔；高吞吐站点与低吞吐站点具有显著的大小阶梯；告警站点外环未被普通站点遮盖。
