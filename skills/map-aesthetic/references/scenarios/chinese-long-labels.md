# 场景决策指南：中文长标注遮挡 (Chinese Long Labels Collision)

中文地名、行政区名或业务站点名称往往包含大量定语、行政后缀和括号备注（例如 `江岸示范园区（西区综合配送站）`），在地图中横向跨度极大。若缺乏文本避让与排版优化，会导致文字大面积互相叠压、穿透点符号或遮挡骨干路线。

## 1. 观察依据 (Observational Basis)

- **文字“叠罗汉”**：相邻的两个地名在水平或垂直方向边界框相交，文字字形笔画穿插粘连，两个名字均无法通顺认读。
- **括号与辅助信息喧宾夺主**：长标注中的括号说明文字（如 `（临时中转点）`）占用了比主体地名更大的视觉面积，导致高层级导向地名被淹没。
- **无描边在深浅交界处吞字**：纯黑文字在穿过深色绿地或深色水体时，由于背景色对比度不足，文字局部笔画断裂看不清。

## 2. 可能原因 (Probable Causes)

- 未启用碰撞检测（Collision Detection）或 SDK 原生避让开关（`declutter` / `symbol-avoid-edges`）。
- 未按地图真实地面分辨率（Meters Per Pixel, MPP）进行层级化注记（Label Tiering）。
- 盲目全量输出原始数据库字段中的超长名称，未针对地图渲染做展示态缩略（Shortening）。
- 缺少文字光晕（Text Halo），字体在不同背景反差下无法保持轮廓。

## 3. 编辑表面 (Editable Surfaces)

- **标注图层布局与样式**：
  - 布局（Layout）：`text-field`（显示内容与格式化）、`text-size`、`text-max-width`、`symbol-placement`。
  - 样式（Paint）：`text-color`、`text-halo-color`、`text-halo-width`。
- **前端数据映射函数**：标注过滤函数 `visible(properties, mpp)` 与文字简写函数 `shorten(name)`。
- **DOM / Popup 弹窗**：保留全量完整名称供点击查阅。

## 4. 优先调整顺序 (Priority Adjustment Order)

1. **依分辨率（MPP）实行层级过滤（Tiering）**：
   - 严禁全量显示所有层级文字。
   - 远景概览（MPP > 8）：仅显示 Tier 0（核心片区/骨干地标名）；
   - 工作视图（3 < MPP ≤ 8）：增加 Tier 1（主干道名）；
   - 局部街巷（MPP ≤ 3）：完整展现 Tier 2（次级道路、商铺门牌）。
2. **长名称排版缩略与去噪**：
   - 地图画布上：提取主干名称（如过滤全角括号内容 `（...）`，限制字数不超过 8 个汉字）；
   - 交互提示上：鼠标悬停或弹出 Popup 时展示完整全名。
3. **施加全天候文字光晕（Knockout Halo）**：
   - 浅色底图：深灰/深墨绿字（`#22282C` / `#405C56`），搭配 `1.5px – 2px` 纯白光晕（`#FFFFFF`）；
   - 深色底图：浅灰白字（`#E0E4E8`），搭配 `1.5px – 2px` 暗底光晕（`#111820`）。
4. **多行折行与对齐**：
   - 设置 `text-max-width: 6 – 8 em`，避免单行横贯半个屏幕，采用居中或随锚点对齐。

## 5. 建议参数范围及适用条件 (Recommended Parameters)

- **字号 (`sizePx`)**：
  - Tier 0（片区名）：`13px – 15px`，字重 `600`（粗体），字间距 `0.05em`
  - Tier 1（主干道）：`11px – 12px`，字重 `500`（中粗）
  - Tier 2（次级名）：`10px – 11px`，字重 `400`（常规）
- **文字光晕宽度 (`haloWidthPx`)**：`1.5px – 2.0px`。低于 1px 起不到隔离作用，高于 3px 会让笔画显得臃肿模糊。
- **文字长度上限**：地图主注记建议控制在 `8 个中文字符以内`。

## 6. 不可破坏的数据语义 (Preserved Data Semantics)

- **不得彻底删除名称**：在缩略地名时，只能用于地图平面的临时注记渲染；DOM 列表、无障碍属性（`aria-label`）以及弹窗（Popup）必须完整保留原始未经截断的全称。
- **不得改变地名所属层级关系**：不能为了避免碰撞把原本属于片区 Tier 0 的注记降权为普通道路。

## 7. 能力不足时的替代方案 (Fallbacks When Capability Is Lacking)

- **轻量前端引擎缺少高级碰撞引擎（如纯 Leaflet）**：
  - 手工按视域/缩放级别编写 `visible: (props, mpp) => ...` 过滤规则；
  - 采用预先计算或运行时轻量包围盒检查，一旦发现 Tier 0 与 Tier 2 冲突，优先隐藏 Tier 2。

## 8. 验收方法 (Acceptance Methods)

- **功能正确性**：点击缩略后的地名注记或对应点位，弹窗中能正确读出完整全称。
- **审美效果评估**：
  - 自动检测或人工审查固定视域：注记重叠对数（Overlapping Pairs）降为 0（特别是涉及 Tier 0 的致命碰撞）；
  - 文字跨越不同底色路网时，笔画边缘因 Halo 的存在清晰锐利。
