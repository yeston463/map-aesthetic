# 场景：城市文化设施地图（验证案例）

本场景是 `demo/cultural-atlas/`：在真实路网上展示博物馆、图书馆、剧院、美术馆、书店、
非遗驿站六类文化场所，按类别上色、按年访问量决定符号大小。它是 `transferable-principles.md`
的**第二个验证案例**——刻意选择了与「街区配送」不同的场景，并刻意使用了不同的配色，用来
检验方法是否可迁移，而不是把某张样张的“纸墨风”复制过来。

## 为什么选这个场景

- 与「配送站点」不同的任务：配送是**顺序量 + 一条路线**；文化设施是**分类数据 +  graduated
  symbol（点大小）**，没有路线。这逼出了 `transferable-principles.md` 的 P4 注意项：分类色
  不能套到顺序数据，反之亦然。
- 与「深色监控」也不同：那是以告警为主角的 monitoring 场景。本场景以“浏览探索”为主，
  底图应退到背景，业务点才是主角。
- 因此本案例同时验证了：分类色板、按量分级、底图克制、标注避让、移动端抽屉——且全部套用
  street-atlas 复用下来的同一套代码骨架（pane / 道路 casing / 标注避让 / 抽屉），只换了
  数据与视觉决策。

## 数据来源与许可（必须保留）

- 底图：`data/context.geojson`、`data/labels.geojson` 与 `data/basemap-provenance.json` 是
  **复用 street-atlas 的真实 OSM 路网快照**（江岸片区，ODbL-1.0）。本案例未重新查询 Overpass；
  如需重生成参考 `street-atlas/build_sample.py`。
- 设施：`data/facilities.geojson` 与 `data/facilities-provenance.json` 为**虚构示例**——
  名称、年访问量、开放年份均为合成，坐标散布在底图范围内但**未吸附到真实地址**，不可用于
  导航。生成脚本：`build_facilities.py`（固定随机种子，可复现）。
- 右下角保留 OSM 署名。

## 设计决策 → 对应原则

| 决策 | 对应原则 |
| --- | --- |
| 复用真实路网做底图，但路网画得比配送样张更轻 | P1（语境）+ P3（道路层次，但克制以免压过业务点） |
| 侧栏 330px、地图占主体；移动端目录收成底部抽屉且默认收起 | P2（地图占主体）+ P6（外壳结构） |
| 六类用分类色，点大小编码年访问量；图例同时给出颜色键与“圈越大访问量越高” | P4（分类 vs 顺序，两者都用到）+ 图例必须与地图编码一致 |
| 路名 + 设施名作为同一批待排布文字做避让 | P5（标注一次性有序集合） |
| 配色用冷色系（teal 强调 + 六类分类色），**不是** street-atlas 的纸墨红 | 证明方法可迁移，风格不是迁移对象 |
| 选中态：描边加粗加深，弹窗出现时抽屉自动收起 | P6（交互让位） |

## 本案例额外验证的 Skill 能力

- `scripts/validate_theme.py` 直接复用于**新配色**：`assets/themes/cultural-atlas.json`
  通过结构、UI 对比度、CIEDE2000 分离度（含色盲模拟）、token 不变式检查。说明配色校验方法
  不依赖旧样张的具体颜色。
- `demo/cultural-atlas/verify.mjs`：5 个视口（桌面/平板/320/390/412）下检查加载、标注不重叠、
  标注不越出地图、选中弹窗不越界、移动端抽屉默认收起/选中收起/可展开、类别筛选显隐、路名开关。

## 刻意的取舍（留待用户判断）

1. **类别筛选只作用于地图，侧栏目录仍列出全部设施、图例仍是完整颜色键。** 这是“目录=全量清单、
   图例=编码说明、筛选=地图显隐”的分工。若你希望筛选也联动目录/图例，需改交互。
2. **底图比配送样张更轻**，是为让分类色突出；若本场景也要强调路网可读性，可调回更重的 casing。
3. **设施坐标为虚构散布**，未吸附真实地址——真实项目应吸附到门牌或建筑轮廓，并校验 POI 与
   底图对齐。
4. **配色经色差校验通过，但“好不好看”未做盲评**：自动检查全绿不等于审美达标（见
   evaluation-status.md）。

## 不适用本场景的方法

- 本场景**没有路线**，因此 `route-road-confusion.md` 的“线路与道路混淆”对策不适用；若加入
  游览动线，则需引入 casing+core 双层。
- 本场景不是示意线路图，因此不适用“主动简化/移除真实地理”的做法。
