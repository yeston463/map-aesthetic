# 场景决策指南：路线与道路混淆 (Route and Road Confusion)

业务折线（如物流轨迹、巡检路线、公交线路）与底图的市政道路（主干道、高架、高速公路）颜色相近、线宽接近、层级混淆，导致用户无法一眼看清业务行动路径。

## 1. 观察依据 (Observational Basis)

- **主次失衡**：在地图中，业务路线的线条与底图上的省道、国道或主干道混在一起，需要刻意凝视才能分辨哪条是业务数据。
- **交叉点粘连**：业务折线在与底图道路重合或交叉时，边界完全融为一体，折点方向感丧失。
- **虚假通达性**：单条业务线在无外轮廓的情况下，容易被误认为是底图绘制的一条普通新建支路。

## 2. 可能原因 (Probable Causes)

- 业务线要素直接复用了底图道路的配色（例如底图高速公路用亮黄或绿色，业务路线也使用同色系）。
- 未使用线外描边（Casing / Outline），线条无法跨越不同底色背景（例如从深色水体穿过浅色陆地时发生视觉截断）。
- 线宽与底图主干道相同（例如均为 3px 或 4px），未拉开层级差距。
- 图层层叠顺序错误：业务线被压在底图注记甚至底图路网下方。

## 3. 编辑表面 (Editable Surfaces)

- **业务矢量图层**：双层线结构（外描边 Casing 图层与核心实体 Line 图层）的 `color`, `width`, `opacity`, `lineCap`, `lineJoin`。
- **矢量底图样式（若可用）**：调暗底图主干道饱和度或将底图道路宽度收窄 10–20%。
- **不可编辑栅格底图**：在业务层采用更强的高对比双层描边结构从位图中“切出”业务线。

## 4. 优先调整顺序 (Priority Adjustment Order)

1. **构建双层线条结构（Casing + Core）**：
   - 增加外描边（Casing）：外描边通常比核心线宽 `2px – 4px`，使用纯白色（浅色主题）或深色/反差色（深色主题），为核心线垫底。
2. **重塑色相隔离（Hue Separation）**：
   - 确保核心线颜色与底图所有已知道路颜色（尤其是高速路橙黄、主干道红黄、普通路白灰）在色相和明度上均有足够的 CIEDE2000 差距（可从 dE2000 15 附近试验，仍需检查实际背景与线宽）。
3. **设置平滑拐角**：
   - 统一配置 `line-cap: round` 和 `line-join: round`，防止折角处出现尖锐毛刺或与底图直角路口混同。
4. **提升渲染层级（Pane / Layer Order）**：
   - 确保路线层位于底图道路之上、文字标签之下（防止路线反客为主压住地名导致迷路）。

## 5. 建议参数范围及适用条件 (Recommended Parameters)

- **核心线宽 (`route.widthPx`)**：`3px – 5px`（过细失去辨识度，过粗会遮挡沿线站点）。
- **外描边线宽 (`route.casingWidthPx`)**：`casingWidthPx = widthPx + (2px ~ 4px)`，推荐 `6px – 8px`。
- **颜色对比**：
  - 浅色分析底图：外描边 `#FFFFFF`，核心线推荐深翡翠绿 `#137C6C` 或蓝灰 `#1A5B8C`。
  - 深色夜间底图：外描边 `#0B1216`，核心线推荐高亮荧光青 `#26A69A` 或亮琥珀 `#FFA726`。
- **线帽与线连接**：`round`（圆角）优于 `miter`（尖角）。

## 6. 不可破坏的数据语义 (Preserved Data Semantics)

- **保持路线拓扑完整性**：不得为了让线条显得“平滑”而盲目增加插值平滑算法，导致折线偏离实际停靠点。
- **保持流向/单双向语义**：如果路线数据包含方向箭头或流动效果，描边必须完整包裹箭头基座，不得破坏流向指示。

## 7. 能力不足时的替代方案 (Fallbacks When Capability Is Lacking)

- **底层引擎不支持单图层双重描边（如原生 Leaflet Polyline）**：
  - 规范做法：在单独的自定义 Pane 中创建两条 Polyline，一条作为 Casing（宽 7px、白底），一条作为 Core（宽 4px、业务绿），坐标数组严格同步。
  - 避免做法：切勿尝试用 CSS `filter: drop-shadow` 伪造描边，这会在移动端与低端设备引起严重的光栅化掉帧和发虚。

## 8. 验收方法 (Acceptance Methods)

- **功能正确性**：两层 Polyline 坐标长度、点位完全一致；点击路线能触发正确交互（若有）。
- **审美效果评估**：
  - 截取路线穿越不同地物（水体、林地、高密度建筑区、普通道路）的局部像素；
  - 核心线与外描边、外描边与背景在截面像素图上具有鲜明的阶跃边界；
  - 路线在缩放到全景时能作为骨架结构被第一眼捕捉。
