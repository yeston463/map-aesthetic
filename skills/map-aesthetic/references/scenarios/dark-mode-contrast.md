# 场景决策指南：深色主题对比不足 (Dark Mode Contrast)

在夜间或暗色监控大屏模式下，底图水体、陆地、道路由于过度调暗导致整体变成“死黑”一片，丢失地形轮廓；或者业务线、点、面要素因对比不足淹没在暗色背景中；或者相反，高亮荧光色刺眼刺目，产生眩光。

## 1. 观察依据 (Observational Basis)

- **死黑与地物丧失**：水体、绿地与普通陆地全在 `#101518` ~ `#12161A` 之间挤压，色差极小（dE2000 < 3.0），用户看不出海岸线、河流或绿地边界。
- **暗夜“迷航”**：道路网络过暗无法提供骨架导向，用户看不出业务点位是分布在哪条街道上。
- **状态失真与眩光**：告警红色或高亮黄色与极暗背景产生过度强烈的视网膜反差，长时间观看引发视觉疲劳，且淹没了相邻的普通业务数据。

## 2. 可能原因 (Probable Causes)

- 机械式使用浅色主题的“色相对调”或负片滤镜（Invert Filter），未根据人眼在暗视觉（Scotopic Vision）下的非线性感知特征重新校色。
- 顺序色带（Sequential Ramp）的明度方向倒置：在浅色模式下通常是“数值越大颜色越深”，但在深色模式下必须反转为“数值越大明度越高（越亮）”，否则大数值面会变成看不见的死黑块。
- 未建立系统化的深色制图色彩契约。

## 3. 编辑表面 (Editable Surfaces)

- **底图矢量样式**：背景色（`land`）、水体色（`water`）、主干道色（`road`）、道路描边色（`roadCasing`）。
- **业务图层 Paint 属性**：路线颜色、站点颜色、面分档色带、文字及文字光晕。
- **DOM UI 组件**：图例、信息面板、控制按钮的背景色（`surface`）、文字色（`text`）与边框色（`border`）。

## 4. 优先调整顺序 (Priority Adjustment Order)

1. **垫实底图基底反差（Anchor Background Contrast）**：
   - 陆地不能直接用纯黑 `#000000`，应使用深青灰（如 `#121E24` 或 `#1B242A`）；
   - 水体使用略具倾向的深墨蓝（如 `#172E3B`），确保水陆边界 dE2000 ≥ 5.0；
   - 道路网络使用中暗灰（如 `#2A3A42`），既不刺眼又能清晰指示道路网架。
2. **反转顺序色带的明度坡度**：
   - 将低数值设为深暗蓝绿（如 `#21413D`），高数值设为明亮青绿（如 `#62B8A8`），遵循“数值大 = 光芒更强/更亮”的自然直觉。
3. **收敛荧光刺目感，增加深色柔光光晕**：
   - 文字使用浅灰白（`#E0E4E8`），光晕使用暗底色（`#111820`）；
   - 告警色使用高辨识但略带柔和的冷红或珊瑚红（如 `#FF6B6B` / `#D32F2F`），避免纯高亮 `#FF0000` 造成的眩光。
4. **统一 UI 面板色彩语义**：
   - 弹窗与控制面板使用略高于底图明度的表面色（如 `#1A2329`），辅以细边框（`#34434D`）与微投影，与地图建立清晰的深度感（Elevation）。

## 5. 建议参数范围及适用条件 (Recommended Parameters)

- **底图色调推荐（参考 [night-operations.json](../../assets/themes/night-operations.json)）**：
  - `land`：`#121E24`
  - `water`：`#172E3B`（与 land 保持 dE2000 ≥ 5.0）
  - `road`：`#25353D`，`roadCasing`：`#182329`
- **业务要素**：
  - 核心路线：`#2CB59A`（亮青绿），描边 `#0D161A`（暗色包边）；
  - 站点选中态：外圈高亮金黄 `#FFB74D` 或冰蓝 `#64B5F6`，内填充保留原业务类色；
- **UI 文本对比度**：正文文字与面板底色对比度必须满足 WCAG 2.1 AA 级（≥ 4.5:1）。

## 6. 不可破坏的数据语义 (Preserved Data Semantics)

- **类别色彩象征意义稳定**：浅色模式下代表“自提点”的色系在深色模式下不得变成代表“枢纽仓”；必须保持统一的色相心理映射。
- **告警等级不可颠倒**：正常与告警状态的对比关系在深浅模式下必须保持一致。

## 7. 能力不足时的替代方案 (Fallbacks When Capability Is Lacking)

- **底图只有浅色栅格瓦片且无法更换服务**：
  - 严禁简单使用 CSS `filter: invert(1)`，因为这会把绿地变成洋红、水体变成橙红等怪诞反常的颜色；
  - 妥协方案：若必须提供夜间模式，使用支持深色样式的矢量底图（如 Mapbox / 高德暗夜版），若无法使用，则保持浅色底图并只调暗页面外围 DOM 边框。

## 8. 验收方法 (Acceptance Methods)

- **功能正确性**：日夜主题切换后，所有数据源、图层、选中状态与弹窗完整保留，不闪烁、不丢失。
- **审美效果评估**：
  - 运行 `python skills/map-aesthetic/scripts/validate_theme.py <night-theme.json>`；
  - 确保水体与陆地、分类色对、连续色带阶梯均通过 `dE2000 >= 5.0` 机器验证；
  - 实际截图中，道路骨架清晰，暗夜氛围静谧而不压抑。
