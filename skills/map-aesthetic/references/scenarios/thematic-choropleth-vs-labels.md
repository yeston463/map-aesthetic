# 场景决策指南：专题面与地名竞争 (Thematic Choropleth vs Labels)

专题分级统计面（Choropleth Polygon）或填充区域的不透明度过高、颜色过深，或者直接盖在底图文字上方，导致底图地名、路名、行政区划注记完全被遮蔽；反之若透明度过低，多边形颜色又与底图地物混叠，导致分级语义失真。

## 1. 观察依据 (Observational Basis)

- **底图文字失明**：填充多边形下方的底图道路名、POI 标签、地铁站名称无法辨认或边缘模糊。
- **色彩混合脏污**：如果直接给面图层赋予高透明度（例如 `opacity: 0.3`），面图层颜色与底图的绿地、水体、黄色主干道颜色直接光学混合，导致原本浅绿的分档颜色在经过黄色底图道路叠加后变成了暗黄色，严重破坏了按颜色读出分档梯度的准确性。
- **无数据与极小值混淆**：缺失值区域直接使用最低阶梯色或默认半透明黑/灰，导致“数据未统计”被误认为是“指标为 0”。

## 2. 可能原因 (Probable Causes)

- 图层堆叠顺序（Z-Index / Layer Order）错误：面图层被放置在底图文字层上方（在栅格底图中必然发生，因为栅格文字烘焙在像素内；在矢量底图中则是未将面图层下沉到文字槽）。
- 选用饱和度过高、明度过暗的顺序色带（Sequential Ramp），使得中高档位面色块变成不透明黑块。
- 未配置或使用了错误的缺失数据处理规范（Missing Data Rule）。

## 3. 编辑表面 (Editable Surfaces)

- **矢量底图环境**：通过 Mapbox Standard 的 `slot: 'bottom'`，或在 Classic 样式中将面图层放置在最底部的 `road-casing` 或 `tunnel` 之前，让所有底图道路和注记自然浮在专题面上方。
- **栅格底图环境**：
  - 在面图层之上建立独立的自定义业务标注层（覆盖关键导向地名）；
  - 精细调整面填充透明度（`fillOpacity`）与边界描边（`boundaryColor` / `boundaryWidthPx`）。
- **主题契约配置**：`cartography.area` 与 `cartography.missing`。

## 4. 优先调整顺序 (Priority Adjustment Order)

1. **下沉图层位置（矢量环境首选）**：将专题面插入到注记图层和道路图层下方。
2. **校准半透明度与饱和度（栅格环境核心）**：
   - 保持中等半透明度（`fillOpacity: 0.35 – 0.55`），既保留分级色彩倾向，又能透出底图道路纹理。
   - 选取低饱和度色系（如淡青绿 `#DEEEE8` ~ `#32826C`），避免使用高饱和红、黑、纯紫。
3. **补充清晰的多边形内边界**：
   - 绘制纤细的高对比边界线（`boundaryWidthPx: 1px – 1.5px`），即使内部填充较淡，各分区间的边界依然后台清晰。
4. **为无数据面（Missing Data）设计纹理与独立色系**：
   - 采用带斜向条纹（Hatch Pattern）或纯中性冷灰（`#DBDBD7`），与有数据的最低档拉开感知距离（dE2000 ≥ 5.0）。

## 5. 建议参数范围及适用条件 (Recommended Parameters)

- **面填充不透明度 (`area.fillOpacity`)**：
  - 矢量底图（在文字下方）：`0.5 – 0.7`
  - 栅格底图（在底图上方）：`0.35 – 0.5`（推荐 `0.45`）
- **边界线宽 (`area.boundaryWidthPx`)**：`1px – 1.5px`；边界颜色使用与最高档色同相的深色，或半透明深灰色。
- **发散色带（Diverging Ramp）中心点**：当数据围绕平均值或 0 上下波动时，必须使用奇数色带（3、5、7 档），中心档位使用极浅中性灰白，两侧发散。

## 6. 不可破坏的数据语义 (Preserved Data Semantics)

- **严禁私自篡改分级断点（Class Breaks）**：分档界限（如 400、800、1200）代表业务统计口径，不能为了“颜色看起来顺眼”而随意调整边界阈值。
- **严禁把缺失值（null / undefined）映射为 0**：缺失必须通过独立图例项和专属模式呈现。

## 7. 能力不足时的替代方案 (Fallbacks When Capability Is Lacking)

- **栅格底图无法将多边形置于地名下方**：
  - 在多边形上方，利用矢量标注图层（或高阶 Pane）重新绘制主要行政区名与骨干路名（带 2px 白色 Knockout Halo）。
  - 在点击多边形时高亮该面边界，而不是加深整块面积的填充颜色。

## 8. 验收方法 (Acceptance Methods)

- **功能正确性**：每个多边形对应的业务指标与图例说明完全吻合；缺失值区域悬停显示“无数据”。
- **审美效果评估**：
  - 底图主干路网在多边形半透明层下连续可见；
  - 相邻分档多边形的色差在实际截图测量中满足 `dE2000 >= 5.0`；
  - 缺失值多边形与任意一档数值多边形色差满足 `dE2000 >= 5.0`。
