## 证据边界

案例回归不等于代理前向评估；色差不等于审美或无障碍保证。
MapLibre 与 Mapbox 不同，Node fake 仅检查控制流，不能证明 SDK 兼容。
缺少凭证不代表所有场景都必须有特定付费方案、企业身份或信用卡。
本轮未重新执行旧版在线引用或 GitHub CI；离线引用检查只确认结构。
