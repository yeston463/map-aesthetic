# Leaflet 本地栅格底图案例

Leaflet 1.9.4 配合本地合成瓦片、业务点线面和中文标注。所有几何均为虚构，
经纬度仅用于演示投影与瓦片索引，不对应真实业务地点。

## 运行

```sh
npm ci
npm run case:serve
```

打开 `/cases/leaflet-raster/?variant=baseline` 或 `?variant=improved`。
`npm run case:verify` 自行启动临时本地服务，检查完成后关闭。
像素采样另执行 `python scripts/measure_case_pixels.py`，需要 requirements-dev.txt。

## 原始状态和改进

- 栅格道路和文字已烘焙进像素，业务样式不能独立改变它们。
- baseline 保留密集标签、单根路线、含义重复的图例及底部面板遮挡等设计问题。
- improved 使用独立 panes、双层路线、类别填充与状态外圈、应用侧标签避让、
  真正的 SVG 缺失值填充纹理，以及基于实际面板位置的平移。
- 顺序色带分四档；相对均值偏差色带分五档，图例分别对应实际分类。
- 图层坐标、业务数值和类别字段保持，状态的表达位置由填充转为外圈，图例同步说明。

[IMPROVEMENT.patch](IMPROVEMENT.patch) 比较两个样式模块；共享 app.js 的行为改动
仍需与 Git diff 一起阅读，它不是整个案例的完整可应用补丁。

## 缩放和状态

本地原生瓦片只覆盖 zoom 14、15；`minNativeZoom` / `maxNativeZoom` 允许在
地图 zoom 13–17 重用这些资源。测试会等待瓦片加载并检查操作后的错误，
避免高缩放时底图空白仍报告成功。

标签避让是针对小型 fixture 的贪心近似，不是 Leaflet 核心能力。长名称的原文
保留在数据及站点列表/弹窗；示例缩略规则不适用于所有地名，真实项目需要检查歧义。
桌面截图固定相机和相同地图尺寸。移动端选择目标后允许为抽屉避让而平移，
相关截图不是未平移的相机对照。

## 探索性变体

`attempt-filter` 仅对瓦片层应用 CSS filter；`attempt-opacity` 只降低瓦片透明度。
它们会影响整个底图的像素，不能实现逐道路改色；当前实现不会改变业务点的填充色。
这些变体是可观察的取舍示例，不是证明所有滤镜或透明度调整都错误的用户实验。
度量值可能增大也可能减小，应结合原始截图和任务判断。

## 数据与复现边界

[data-manifest.json](data-manifest.json) 记录生成资源的 SHA-256。
数据生成器需要 Pillow 和中文字体；`CASE_FONT` 可指定本地字体文件。
相同种子不保证不同 Pillow 或字体版本下的 PNG 字节一致。仓库中的提交资源
可直接运行，无需先重新生成。

案例回归验证手写实现的行为；它没有单独执行代理改造任务，因此不能用来
证明 skill 相比普通提示词的效果。独立评估状态见仓库 evals 记录。
