# Mapbox 真实集成：尚未完成的验证

当前已运行的是 MapLibre 本地 GeoJSON 案例。Mapbox GL JS、Standard、
Mapbox 托管底图、字体资源与账号权限均未在本轮运行。

1. 使用目标项目实际安装的 Mapbox SDK 和版本，按该项目现有方式提供凭证。
   本仓库没有确认用户账号权限，不推断所有场景都需要特定付费方案或信用卡。
2. 确认实际样式家族和资源来源。Classic 日夜样式分别检查真实图层 ID，
   提供 `classicBefore`；Standard 检查所用版本、公开配置和 slots。
3. 确认输入数据使用稳定 ID；示例保留已有 feature ID，固定 fixture 的索引回退
   不适合会重排或增删的实时数据集。
4. 在资源就绪后应用主题，验证首次加载、日夜切换、失败恢复、选择、弹窗和卸载。
   `setStyle` 的加载过程可能出现暂态，不能直接承诺无闪烁或无短暂缺层。
5. 检查字体、实际语言、图层顺序、投影、地形、窄屏和所需版权信息。
   本地中文字体结果不能代替真实 glyph 服务验证。
6. 为目标项目制定有上限的资源就绪和错误处理；仅监听 `style.load` 不足以证明
   所有瓦片、图标、文字已经显示。不要照搬本地 fixture 的网络配置。
7. 用真实 SDK 重跑并保存版本、代码 revision、资源、视域、截图和交互结果，
   再更新支持矩阵。Node stub 测试和 MapLibre 测试分别保留原有证据标签。
