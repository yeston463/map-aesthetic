# 江岸配送图：界面与地图视觉探索

这个独立演示在既有的合成配送地图上重新设计了界面与三套地图配色。纸色、墨色、朱红、排版和分隔方式参考了 [zou-frontend](https://github.com/Young-518/zou-frontend) 的整体视觉思路；没有引用该仓库的图片、字体或源码。站点、道路与片区都是本地合成示例，不代表真实地点或业务。

## 预览

在项目根目录启动本地服务器：

```powershell
node cases/serve.mjs
```

打开 <http://127.0.0.1:4174/demo/three-directions-zou/>，通过顶部的「清简运营 / 纸墨街区 / 墨金夜图」切换。若 4174 端口已有本项目的服务器在运行，直接打开即可。手机端可展开站点目录；选择站点后，目录自动收起并显示详情。

演示复用同级 `../three-directions/` 中的本地数据、Leaflet 和可选栅格资源，因此移动目录时要保留这一依赖关系。默认不请求在线地图或模型 API。

## 复核与截图

服务器运行后，从项目根目录执行：

```powershell
node demo/three-directions-zou/capture.mjs
```

截图及 `capture-report.json` 写入 `output/playwright/zou/`。脚本覆盖三种风格、桌面和四种手机宽度，检查站点弹窗、目录遮挡、关闭按钮、标注位置、样式切换、图层状态及三种风格的数据一致性。结果仅覆盖脚本实际运行的视口、站点和状态，不构成完整可访问性认证，也不是之前 A/B 盲评实验的结果。
